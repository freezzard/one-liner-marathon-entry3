Entry for the make.fun bounty **One-Liner Marathon**. `main.ts` deterministically writes one original one-line comedy joke (152 characters) to `/output/entry.txt`. The joke works by absurd literalism: a mundane premise — an elevator carrying people — followed through to an outsized consequence, anchored by one concrete detail. The pick is fixed: every run writes byte-identical output.

## Run it

```sh
node main.ts
```
